# Atlas de Estética

Painel de estudo de história da arte com foco em arquitetura e urbanismo, da pré-história ao Neoclassicismo.

**Organização do material:** Ana Madruga

Site: https://estetica.anamadruga.com

## Conteúdo

- `index.html`: o site completo (página única, sem dependências de build).
- - `Dockerfile`: imagem nginx que serve o site, usada no deploy pelo EasyPanel.
